  • API 키와 접속 토큰은 서버로 보내지 않습니다. 이용자의 기기에만 있습니다.
  • 구글 계정으로 로그인하면 가계부·거래처·명함 등 업무 기록만 서버에 보관됩니다.
  • 로그인하지 않으면 서버에 아무것도 저장되지 않습니다.
  • 보관 서버는 미국(Cloudflare)에 있습니다. 제5조에 자세히 적었습니다.
  • 앱 안에서 언제든 직접 삭제할 수 있습니다.

제1조 (총칙)

포도야(이하 "서비스")는 이용자의 개인정보를 소중히 다루며, 개인정보 보호법 등 관계 법령을 지킵니다. 이 방침은 서비스가 어떤 정보를 어떻게 다루는지 알리기 위해 만들어졌습니다.

제2조 (수집하는 정보)

서비스는 자체 회원가입을 받지 않습니다. 비밀번호·주민등록번호·계좌정보를 수집하지 않습니다.

구분항목수집 시점
필수구글 계정 식별번호, 이메일 주소, 이름구글 로그인 시
선택가계부 · 거래처 · 명함 · 일정 · 설정 등 업무 기록로그인 후 자동 보관 시
자동접속 일시서비스 이용 시
로그인하지 않으면 서버에 아무것도 저장되지 않습니다. 구글 로그인은 선택 기능이며, 하지 않아도 서비스의 모든 기능을 쓸 수 있습니다. 다만 그 경우 폰을 잃으면 기록을 되찾을 수 없습니다.

제3조 (서버로 보내지 않는 정보)

다음 정보는 이용자의 기기에만 저장되며, 어떤 경우에도 서버로 전송되지 않습니다.

  • Claude · Gemini 등 AI 서비스 API 키
  • 카카오 · 텔레그램 · 구글 캘린더 등 연동 서비스 접속 토큰
  • 검색 서비스 API 키, 자동화 서비스 인증 정보
  • 알림 수신 등록 정보

앱이 서버로 자료를 보낼 때 이름 규칙으로 위 항목을 걸러내며, 서버도 받은 자료에서 같은 항목을 한 번 더 걸러 버립니다. 기기를 바꾼 경우 위 정보는 복원되지 않으며, 직접 다시 입력해야 합니다.

이는 불편이 아니라 의도된 설계입니다. 운영자가 이용자의 API 키를 보관하지 않으므로, 서버가 유출되더라도 이용자의 외부 서비스 요금이 청구되는 일이 발생하지 않습니다.

제4조 (정보를 쓰는 목적)

  1. 본인 확인 — 어느 이용자의 기록인지 구분하기 위해 구글 계정 식별번호를 씁니다.
  2. 기록 보관과 복원 — 기기를 바꾸거나 잃었을 때 업무 기록을 되찾게 하기 위해
  3. 문의 응대 — 이메일 주소로 연락하기 위해
  4. 수집한 정보는 위 목적 외에는 쓰지 않습니다. 광고·마케팅에 쓰지 않고, 판매하지 않으며, 내용을 분석하지 않습니다.

제5조 (국외 이전)

보관된 정보는 아래 사업자의 국외 서버에 저장됩니다.

업체맡기는 일보내는 것국가
Cloudflare, Inc.서버 운영 · 자료 보관구글 계정 식별번호, 이메일, 업무 기록미국 등
Google LLC로그인 본인 확인구글 로그인 토큰미국

이전 시점 — 이용자가 구글 로그인을 하고 자료가 보관될 때
이전 방법 — 암호화된 통신(HTTPS)을 통한 전송
보유 기간 — 제7조에 따름

동의를 원하지 않으시면 구글 로그인을 하지 않으시면 됩니다. 로그인 없이도 모든 기능을 이용할 수 있으며, 이 경우 국외 이전이 발생하지 않습니다.

제6조 (기기에 저장되는 정보)

  1. 모든 기록은 먼저 이용자 기기의 브라우저 저장공간에 저장됩니다. 서버 보관은 그 사본입니다.
  2. 로그인하지 않은 경우 기기에만 존재하며, 브라우저 데이터를 지우면 함께 사라집니다.
  3. 앱의 마이 탭 → 데이터 백업에서 기기 저장분을 파일로 내려받거나 지울 수 있습니다.

제7조 (보유 기간과 파기)

  1. 업무 기록 — 이용자가 직접 삭제하거나, 마지막 접속일로부터 2년이 지나면 삭제합니다.
  2. 로그인 정보 — 유지 기간은 60일이며, 그 뒤 자동으로 만료됩니다.
  3. 계정 정보 — 이용자가 삭제를 요청하면 지체 없이 삭제합니다.
  4. 삭제된 정보는 복구할 수 없습니다.

제8조 (이용자의 권리와 삭제 방법)

이용자는 언제든 아래를 직접 할 수 있습니다.

하고 싶은 것방법
서버 보관분 삭제마이 탭 → 계정 · 안전 보관 → 서버에서 완전 삭제
이 기기에서 로그아웃마이 탭 → 계정 · 안전 보관 → 로그아웃
기기 저장분 삭제마이 탭 → 데이터 백업, 또는 브라우저 데이터 삭제
내 자료 내려받기마이 탭 → 데이터 백업 → 백업 파일로 내보내기
구글 연결 끊기구글 계정 → 보안 → 타사 앱 연결

열람·정정·삭제·처리정지를 요청하시려면 아래 연락처로 알려주시면 처리합니다.

제9조 (제3자 제공)

  1. 운영자는 이용자의 정보를 제3자에게 제공하거나 판매하지 않습니다.
  2. 다만 법령에 따라 수사기관이 적법한 절차로 요구하는 경우에는 제공할 수 있습니다.
  3. 제5조의 국외 이전은 서비스 제공을 위한 처리위탁이며, 제3자 제공과는 다릅니다.

제10조 (이용자가 직접 연결하는 외부 서비스)

  1. 이용자가 자신의 API 키를 입력해 Claude, Gemini 등 AI 서비스를 이용하는 경우, 입력한 내용은 이용자의 기기에서 해당 사업자에게 직접 전송됩니다. 운영자의 서버를 거치지 않으며, 운영자는 그 내용을 볼 수 없습니다.
  2. 해당 사업자의 개인정보 처리는 각 사업자의 방침을 따릅니다.
  3. 운영자는 이용자가 연결한 외부 서비스의 장애·정책 변경에 대해 책임을 지지 않습니다.

제11조 (아동의 개인정보)

서비스는 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만 아동이 이용하려면 법정대리인의 동의가 필요합니다.

제12조 (안전성 확보 조치)

  1. 모든 통신은 암호화(HTTPS)로 이루어집니다.
  2. API 키·접속 토큰은 구조적으로 서버에 도달하지 않도록 앱과 서버 양쪽에서 차단합니다.
  3. 로그인 정보는 임의로 생성된 값으로 관리하며, 60일 뒤 자동 만료됩니다.
  4. 운영자는 보관된 업무 기록을 열람하지 않으며, 통계·분석에 사용하지 않습니다.

제13조 (방침의 변경)

  1. 이 방침이 바뀌면 이 페이지에 게시합니다.
  2. 이용자에게 중요한 변경은 시행일 7일 전부터 앱 안에 알립니다.
